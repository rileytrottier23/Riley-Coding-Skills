# Anthropic example skills (engineering)

Vendored from [anthropics/skills](https://github.com/anthropics/skills) at commit
[`f379e5a`](https://github.com/anthropics/skills/tree/f379e5ad66e2febc1616cf8d6284666fecbe514e),
synced 2026-08-18. **Not my work** — pinned here so the versions I actually run are diffable, and kept
under their original license.

Each is a **folder** — `SKILL.md` plus scripts, references, and assets, and its own `LICENSE.txt`.
Copy the whole directory, not just the markdown.

The writing, comms, and creative Anthropic skills (doc-coauthoring, internal-comms, algorithmic-art,
brand-guidelines, theme-factory, slack-gif-creator, claude-academy-guide, discernment-nudge) live in
[riley-thinking-skills](https://github.com/rileytrottier23/riley-thinking-skills) instead; this folder
holds the engineering ones.

| Skill | What it does |
|---|---|
| [mcp-builder](./mcp-builder) | Guide for building high-quality MCP servers that expose external services to LLMs through well-designed tools. |
| [webapp-testing](./webapp-testing) | Playwright-based toolkit for driving and testing local web apps — verifying frontend behavior, debugging UI. |
| [web-artifacts-builder](./web-artifacts-builder) | Tools for building elaborate multi-component claude.ai HTML artifacts with React, Tailwind, and modern web tech. |
| [frontend-design](./frontend-design) | Guidance for distinctive, intentional visual design when building or reshaping UI — typography, layout, aesthetic direction. |
| [claude-api](./claude-api) | Reference and client examples for the Claude/Anthropic API across several languages. |
